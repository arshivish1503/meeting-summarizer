# Meeting-Notes-to-Action-Items Summarizer

Use Case #9 — App

## Run
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Deploy (Streamlit Cloud)
Push `app.py`, `requirements.txt`, `samples/` to GitHub → share.streamlit.io → New app → `app.py`.

## Gemini key (optional)
Get free at https://aistudio.google.com/app/apikey → paste in sidebar. Without key, rule-based extractor is used.
